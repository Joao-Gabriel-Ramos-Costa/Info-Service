# InfoService — Projeto de Miniempreendimento

O **InfoService** foi um projeto desenvolvido para o **Instituto Federal de Minas Gerais (IFNMG)** durante minha participação em uma **bolsa escolar remunerada**. O objetivo foi desenvolver um site para um miniempreendimento, colocando em prática conhecimentos de desenvolvimento web e adquirindo experiência com um projeto desenvolvido de forma mais organizada e profissional.

Durante o desenvolvimento, tive meu primeiro contato prático com um **framework front-end**, utilizando o **Bootstrap**, além de aprofundar meus conhecimentos em **HTML5 e CSS3** para estruturar e estilizar as páginas. Também utilizei **JavaScript** em funcionalidades pontuais do projeto.

Esse projeto foi importante para minha evolução porque me permitiu transformar conhecimentos adquiridos durante o curso técnico em uma aplicação prática, trabalhando aspectos como **estruturação de páginas, responsividade, organização de código, componentes do Bootstrap e desenvolvimento de interfaces web**.

Além dos conhecimentos técnicos, o projeto contribuiu para o desenvolvimento de habilidades importantes para o mercado de trabalho, como **organização, responsabilidade, resolução de problemas e desenvolvimento de projetos seguindo uma proposta real**.

### Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap

### Objetivo

O projeto teve como principal objetivo aplicar conhecimentos de desenvolvimento web na criação de uma solução para um miniempreendimento, proporcionando uma experiência prática de desenvolvimento e contribuindo para minha preparação para atuar profissionalmente na área de tecnologia.
